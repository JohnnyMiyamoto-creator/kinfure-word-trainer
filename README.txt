金フレ単語トレーナー（Android向けWebアプリ）

機能：弱点単語112語、範囲選択、ランダム出題、「わかる／わからない」記録、回答後の意味表示、要復習のみ出題、端末内保存、JSONバックアップ・復元。

サーバー側のデータベースは不要です。学習記録はブラウザのlocalStorageに保存され、外部送信しません。Android Chromeでホーム画面に追加し、PWAとして使うには通常HTTPS配信が必要です。GitHub Pagesなどの無料静的ホスティングなら、バックエンドサーバーの運用は不要です。初回読み込み後はオフライン利用に対応します。ブラウザのサイトデータ削除で記録が消えることがあるため、定期的にバックアップしてください。

導入手順：ZIPを解凍し、ファイル一式をGitHub PagesなどHTTPS対応の静的ホスティングへ配置。Android Chromeで公開URLを開き、メニューから「ホーム画面に追加」または「アプリをインストール」を選択します。

ファイル：index.html（本体と単語データ）、manifest.json、service-worker.js、icon.svg。
