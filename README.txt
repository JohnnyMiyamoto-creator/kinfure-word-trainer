金フレ単語トレーナー（395語）更新版

内容:
- 金フレの弱点395語（1〜1000番の範囲）
- 意味表示、○即答できた／△あやしい／×即答できない の記録
- 範囲別出題、苦手語・未確認語の復習、順番シャッフル
- 学習記録の端末内保存、JSONバックアップ／復元
- オフライン対応（GitHub Pagesで一度開いた後）

GitHub Pages更新手順:
1. ZIPを展開する。
2. GitHubの kinfure-word-trainer リポジトリを開く。
3. index.html、manifest.json、service-worker.js、icon.svg、README.txt を新しいファイルで置き換える。
4. Commit changes を押す。
5. 公開ページを開き直す。更新されない場合はChromeでページを再読み込みし、必要ならサイトデータを消して再度開く。

注意:
- 学習記録はブラウザのlocalStorageに保存されます。アプリのURLやブラウザデータを変えると別記録になる場合があります。
- 意味は学習用の訳の目安です。文脈によって訳が変わる単語もあります。
